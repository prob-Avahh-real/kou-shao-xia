# 银河护卫队 · 口哨冒险

以《银河护卫队》角色与绝招为设定的俯视角冒险游戏。核心玩法是**勇度的口哨飞箭**——按住口哨并滑动手指（或对着麦克风吹口哨），引导飞箭沿轨迹穿梭、弹射穿敌，松手后归返。

## 英雄与绝招

| 角色 | 绝招 | 机制 |
|------|------|------|
| **勇度** | 口哨飞箭 | 按住口哨 + 滑动控箭，弹射穿敌后归返 |
| **星爵** | 元素双枪 | 扇形连射清场 |
| **卡魔拉** | 死亡舞步 | 向前疾冲斩击 / 穿越危险区 |
| **德拉克斯** | 蛮力冲撞 | 撞碎脆弱墙、击飞敌人 |
| **火箭** | 陷阱火箭 | 部署感应地雷 |
| **格鲁特** | 藤蔓缠绕 | 定身周围敌人 |

## 启动

```bash
cd /Users/skat/Projects/guardian-adventure
npm install
npm run dev
```

浏览器打开 Vite 输出的地址（通常 `http://localhost:5173`）。

## 操作

- **左侧摇杆**：移动
- **口哨按钮 / 右侧滑动区**：按住口哨，滑动引导飞箭轨迹
- **麦克风**：点击「🎤 口哨」后，吹口哨可自动施放飞箭
- **切换**：站在蓝色英雄平台时，点「切换」或底部英雄栏换角
- **键盘**：WASD 移动，空格绝招，Q/E 切换英雄

## 技术说明

- 移动端优先 Canvas 游戏，支持手表/眼镜窄屏布局
- 无 DOM 游戏逻辑在 `src/game.js`，便于单元测试
- 灵感来自银河护卫队勇度口哨控箭，角色为玩法向原创呈现，非官方授权
